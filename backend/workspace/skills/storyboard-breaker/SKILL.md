# 分镜拆解指南

## 核心定义：分镜段落

一个分镜 = 一个 **分镜段落**（segment）= 一个视频生成任务。

- 先保留完整对白，再按实际发声、动作与表演预算决定段落时长与子镜头数，时长处于当前模型的有效范围内
- 子镜头之间**可以切镜**：换景别、换角度、换拍摄对象，用硬切衔接
- 子镜头之间**不跨场景**：一个段落只发生在一个场景内（`scene_id` 是段落级绑定）
- 一个段落可包含多个关键画面，后续仍在同一个格组内规划和出图；不要求每句台词或每次切镜新建格组
- 同一机位可以承载连续对白；每个子镜头聚焦有叙事意义的动作、反应或观察，不按固定秒数制造切镜

## 拆分流程（四步）

1. 调用 `read_storyboard_context` 读取剧本、角色、场景、道具、已有分镜摘要
2. **对白与节拍识别**：完整保留剧本中的台词、旁白、说话人和顺序，再识别动作和叙事节拍。不得静默删减、省略、改写或截断台词；节拍标记不能强制切断未完成的句意或因果链
3. **对白预算**：逐句估算发声、标点停顿、换人接话、动作与表演余量，确认每句都能在分配时间内自然说完
4. **自然分段与切镜**：沿自然语义边界、说话轮次、动作完成点与场景变化分段；场景变化必须切段。同一场景内可安排多个子镜头，但不要求每句切镜。补齐 `description` 与 `video_prompt`，按工具上限分批调用 `save_storyboards` 保存完整集

## 对白与模型时长

- 中文台词和旁白保守按每秒 4 个汉字估算，spokenChars 只计实际发声正文，不含说话人标签、空白和标点；其他语言按自然语速保守估时。
- 预算公式：dialogueSeconds = spokenChars / 4 + pauseSeconds + handoffSeconds + actingSeconds。pauseSeconds 为标点与句间停顿，handoffSeconds 为换人接话与反应，actingSeconds 为必要动作与表演余量，分别按内容预留。
- duration 不得小于完整发声与必要表演预算，必须处于当前视频模型的时长范围内；若只支持离散档位，选择能容纳全部内容的档位。
- 超出模型上限时沿完整语义单位、说话轮次或动作完成点拆成相邻段落，长句装不下也只能按完整句意分开，后段接续原文并正确绑定场景、角色与道具。不得以加速念白、缩写台词或省略尾句解决。
- 无对白段落按可见动作、空间建立和必要停留估时。整集总时长是实际预算的结果，不按剧本总字数、目标段数或固定镜头数配额压缩内容。

## 视频时间轴

- `video_prompt` 第一行列出实际出场的 @角色名、@场景名，必要时加 @道具名，名称与资产列表完全一致。
- 之后按对白完成、动作变化和自然切镜边界写可变时长的时间行；从 0 连续覆盖到 duration，无重叠、无空缺，不按固定秒数切块。
- 保持 `description` 中 `【镜头N】` 的切镜顺序；同一台词可在有依据的反应镜头下继续，切镜不能丢失或重复对白。
- 保存前逐句核对剧本、description 与 video_prompt，全部台词与旁白必须覆盖且顺序一致。

## 镜头要素

1. **镜头标题**：3-5字概括段落核心内容（如"噩梦惊醒"）
2. **时间**：具体时分 + 光线描述
3. **地点**：场景完整描述 + 空间布局 + 环境细节
4. **景别**：段落内主导景别；多景别段落写组合，如"中景+特写"
5. **角度**：平视/仰视/俯视/侧面/背面
6. **运镜**：固定/推镜/拉镜/摇镜/跟镜/移镜（段落内不同子镜头可不同）
7. **画面描述** `description`：按 `【镜头1】…【镜头2】…` 逐子镜头描述观众实际看到和听到的内容——画面（谁 + 具体动作 + 肢体细节 + 表情）写在前；该子镜头有台词时以「角色名说：「台词」」写在对应 `【镜头N】` 内，旁白写「旁白：内容」
8. **画面结果** `result`：段落结尾的即时后果 + 视觉细节
9. **氛围** `atmosphere`：光线 + 色调 + 声音 + 整体氛围
10. **时长** `duration`：完整对白与动作能自然完成，且满足模型的有效时长范围
11. **场景关联**：若能匹配已有场景，必须填写 `scene_id`
12. **角色关联**：填写 `character_ids`，绑定当前段落涉及的 0 到多个角色
13. **道具关联**：填写 `prop_ids`，绑定当前段落出现的关键道具（0 到多个）

## 场景关联规则

- 优先使用 `read_storyboard_context` 返回的 `scenes`
- `location + time` 可明确匹配时，必须回填正确 `scene_id`
- 不要凭空生成不存在的场景 ID
- 如果剧本内容明显落在已有场景中，不要重复创造新场景描述

## 角色绑定规则

- `character_ids` 必须从 `read_storyboard_context` 返回的角色列表中选择
- 一个段落可以没有角色，也可以绑定多个角色
- 只要段落里有明确出场、被看见、发生动作或说话的角色，都应绑定进去
- 纯环境段落、空镜、物件特写可以传空数组

## 道具绑定规则

- `prop_ids` 必须从 `read_storyboard_context` 返回的道具列表（`props`）中选择
- 道具被角色使用、交接、特写，或在画面中明显可见且对叙事有意义时，必须绑定到该段落
- 道具特写段落（无角色）也应绑定道具，`character_ids` 可为空
- 与剧情无关的背景物品、场景陈设不要绑定；没有道具出现的段落传空数组
- 绑定的道具会作为视频生成的参考图（白底单品图），保证道具外观跨段落一致

## 质量要求

- `description` 要适合人读，按子镜头详细描述观众实际看到和听到的内容；台词/旁白直接写在对应 `【镜头N】` 内
- `image_prompt` 要突出单帧构图、角色外观、环境和光线（对应段落第一个子镜头）
- `bgm_prompt` 和 `sound_effect` 用简洁短语即可，但不能空泛到只有“紧张”“悲伤”
- 如需调整，调用 `update_storyboard` 修改具体段落
