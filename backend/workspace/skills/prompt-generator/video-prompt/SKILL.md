# 视频提示词（分镜段落 → video_prompt）

根据单个分镜段落的 description（含【镜头N】子镜头结构与台词/旁白）/ atmosphere / duration，生成驱动 AI 视频生成的 `video_prompt`。一个分镜段落对应一次视频任务，多个关键画面仍在同一个格组内；不要求每句台词或每次切镜独立生成格组。内部允许按叙事需要切换景别、角度或对象，但全程不跨场景、不闪回。

## 格式

`video_prompt` 的**第一行是信息头**：先介绍这条视频有哪些人物和场景，然后再接时间分段。人物、场景一律用 @ 引用（生成时会替换为对应参考图片标记，让视频模型先对上"谁"和"在哪"）。

```
出场人物：@小明、@小红；场景：@咖啡厅。
0-2秒：@咖啡厅，中景固定镜头，@小明坐在桌边，手指轻敲桌面。
2-5.5秒：切到门口全景，门铃响，@小红推门走入，停在桌旁。
5.5-10秒：切回双人中景，@小红看向@小明说：「你终于来了。」；小明抬头与她对视，停顿后放松手指。
```

信息头规则：
- 只列该分镜段落实际出场的人物和绑定的场景，不要列没出场的
- 有明显道具出场时可在信息头追加（如 `；道具：@信件`）
- 信息头独立一行，以句号结尾，之后是时间分段

按自然语义、动作和切镜边界写可变时长时间行，每行单独换行；从 0 连续覆盖到 duration，无重叠、无空缺。示例中的时间只对应示例内容，不是固定模板。

## 与分镜描述的映射

`description` 是 video_prompt 的唯一内容来源（画面、动作、台词、旁白都在其中），转换规则：

- 按 `description` 的 `【镜头N】` 顺序覆盖原有子镜头，切镜点与原结构对应；不为凑时间行新增子镜头，也不固定每个子镜头的时间行数
- 完整保留对应 `【镜头N】` 内的全部台词、旁白、说话人和顺序，不得静默删减、省略、改写或截断；不要创作 description 之外的新台词
- 画面动作以 `description` 为准；`atmosphere` 只用于补各段的光线、色调与氛围描写

## 段内结构

每一段按此顺序组织内容（可省略无内容的项，但动作/画面必须有）：

**时间范围 ＋ 场景@引用 ＋ 景别/运镜 ＋ 角色@引用＋主体动作·表情 ＋ 对白/旁白 ＋ 氛围光线**

- **第一段必须建立空间**：场景 + 机位 + 角色的位置与状态，让观众一眼知道在哪、看谁
- **切镜**：切镜后的段开头用"切到/切回"等衔接词，并重新交代景别与主体；切镜点应对齐分镜 `description` 中的 `【镜头N】` 结构
- **景别/运镜**：每段一个镜头状态（近景/中景/全景/特写；固定/推/拉/摇/跟）；单个子镜头内运镜连续，切镜后可更换运镜方式
- **动作**：每段一个主动作，动词具体可见（走、转身、抬头、攥紧、停顿）
- **情绪全部转为可见描写**：不要"他很伤心/气氛紧张"这类抽象词，写成"他低下头、手指攥紧杯沿、呼吸变重"
- **对白/旁白**：写「角色名说：「台词」」，旁白写「旁白：内容」；同一机位可承载多句对白，有依据的反应镜头下也可继续发声，不强制每句切镜。跨时间行的长句按完整语义接续，不丢失或重复正文；无对白的行可写环境音/动作音

## 引用规则

- `@场景名` — 场景引用，名字必须与场景列表中的地点完全一致
- `@角色名` — 角色引用，名字必须与角色列表中的名字完全一致
- `@道具名` — 道具引用，名字必须与道具列表中的名字完全一致；道具在画面中明显可见、被使用或特写时引用
- 生成时会自动把 `@名字` 替换为对应参考图片标记（如 `@小明` → `@图片1小明`），因此名字必须精确匹配，不要缩写或加额外符号
- **每段至少一个 @ 引用锚定画面**；角色出场的段必须 @ 该角色；只引用该分镜段落已绑定的场景/角色/道具

## 对白与时间轴规则

- 中文对白和旁白保守按每秒 4 个汉字估算，spokenChars 不含说话人标签、空白和标点；其他语言按自然语速保守估时。
- 使用 dialogueSeconds = spokenChars / 4 + pauseSeconds + handoffSeconds + actingSeconds；分别预留标点与句间停顿、换人接话与反应、必要动作及表演余量，逐句检查时间能容纳完整发声。
- duration 必须足以容纳内容，并处于当前模型的有效时长范围内。若预算超出现有 duration 或模型上限，停止保存该条，明确报告分镜 ID、原时长、所需时长和沿完整语义拆分的建议。只生成 video_prompt 时不自行修改 duration、description 或重拆整集，不保存缺少对白的提示词。
- 各行时间范围相加必须等于段落总时长，不按固定秒数推算行数；切镜和台词分配以完整语义与实际表演节奏为准。
- 内容节奏：第一段建立 → 中段推进动作/冲突 → 末段落到结果或情绪点

## 禁止事项

- 跨场景切换、闪回（一个段落只发生在一个场景内）
- 引用列表之外的场景/角色名
- 抽象心理描写、文学化比喻（模型只认可见画面）
- 语言与会话语言指令不符

## 保存

只有通过完整对白与时长检查后才调用 `update_storyboard` 保存，仅更新该分镜段落的 `video_prompt` 字段。超出预算按上述规则报告，不要改动其他字段，不要重新拆分整集。
