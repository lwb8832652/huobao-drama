# 分镜画面拆分指南

## 核心定义

- 一个镜头 = 时间线上的一个分镜段落，对应一次连续叙事。
- 一张画面 = 该镜头在某个时刻的关键状态，用于预演和后续视频生成。

## 拆分原则

1. 先用 `read_previs_context` 读取镜头的画面描述、氛围、时长、景别、运镜、场景与绑定素材，不臆造资料之外的信息。
2. 画面数量由用户指定（通常 2-6 张），按时长与动作节奏分配时间点。
3. 画面必须按时间推进：开场状态 → 关键动作瞬间 → 结束状态；相邻画面要有可感知的变化（动作/构图/景别至少其一不同）。
4. 每张画面的 prompt 是可直接用于生图的一句话，按「主体 + 动作/状态 + 景别 + 构图 + 光线氛围」组织；不要在 prompt 里出现镜头编号或解释文字。
5. 遵循项目风格描述（若上下文提供），不自行添加风格词。

## 输出

只输出一个 JSON 对象：

```json
{"frames":[{"title":"开场画面","prompt":"..."},{"title":"关键瞬间","prompt":"..."},{"title":"结束画面","prompt":"..."}]}
```
