# 对白与镜头统一规划验证记录

## 实现范围

- 一个分镜生成多张连续画面的方式保留；统一对白、自然时间预算、子镜头、画面与视频提示词。
- 按语速、标点、换人及表演余量估时；延长优先，超过15秒保守规划预算或9个可视子镜头才拆段。完整保留对白及说话人。
- 整集检查支持选段、预览、查看完整建议、取消、应用到新工作版；显示增加时长和视频生成段数，不自动提交生图或视频。
- 应用采用 revision、源数据指纹和输入摘要防冲突，事务内新增工作版与分镜。保留旧版、图片、视频和音频；变化后的画面必须重规划审阅。
- 图片、宫格和视频生成前拦截未审阅画面或明确的对白/时间/覆盖错误。Agent 保存同样检查完整性和时间，不把旧提示词当本次成功。

## 自动验证

后端13个相关测试文件，113项通过；覆盖真实长对白、漏词、乱序/重复、声线类型、说话人、引号内冒号、英文语速、时间越界、九宫格上限、规则草稿确认、画面映射、事务回滚、源数据冲突、历史素材保留、生成前无副作用拦截与 Agent 写入凭据。

前端7个相关测试文件，134项通过；覆盖预览/应用、保存及轮询竞争、取消无写入、版本冲突、规则草稿审阅、画面数自动建议、参考素材与宫格交互回归。后端 tsc --noEmit、前端 nuxt build 通过。

前端全量测试曾运行：184通过，25失败。剩余失败涉及既有 app/pages 动态路由旧路径、旧 UI 文案/供应商断言，不代表本次相关测试通过全量；本轮没有修改这些无关断言。

## 浏览器验证

使用本地真实第1集的数据库备份，在隔离端口5695后端/5683前端操作；模型配置禁用且服务地址指向不可用本机端口，避免真实生成。

- 进入视频制作，显示整集对白与时间检查。
- 预览13个原始分镜，11个待优化分镜由155秒增加到220秒，整集182秒到247秒；13个分镜规划为21段，增加8次未来视频生成。
- 取消预览不新增工作版；确认应用后得到新工作版，原13分镜旧版可读取。
- 已有图片和历史输出保留；相关输出标记需复核，画面重规划入口可用，直接生成受到拦截。
- 新工作版再次预览、取消无写入，页面无未捕获脚本错误。预览后自动滚动并聚焦摘要。

业务数据库未自动应用方案，未发起付费图片/视频请求。最终成片对白完整性仍需听审；本轮没有接入 ASR 或 TTS 实测。
