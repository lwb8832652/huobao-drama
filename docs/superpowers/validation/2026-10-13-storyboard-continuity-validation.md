## 实现范围

保留一分镜 1～9 个静态画面、一次联合宫格请求，沿用最新 dev 自动采用、两种微调与候选版本回退。AI 规划包含视觉锚点、当前资产、完整风格、已有画格与前后边界。宫格实际输入包含相关场景/人物/道具、共同与画格参考，以及适用时的上一分镜已采用末格。

视频模式可选自动、画面参考、首尾帧。当前已实现 Wan 3.0 两个模型、MiniMax H3 的端点传输；Seedance/Nuwax 保留参考模式。强连续要求同场景、已知兼容帧级机位/景别、没有允许变化且明确边界状态无矛盾，后镜才能共用前镜末格。普通切镜、反打、变化状态使用当前首格；场景/时间切换解除上镜参考。

所有输入冻结来源与摘要。上游变化、时间线重排、来源本地文件覆写/删除会标记过期；不自动产生连锁模型请求。多项宫格 API 使用提交时已有的前镜边界，不宣称取得同批刚生成的上游结果。

通过七组验证（无页面脚本错误）：

1. 规划：参考缩略图正常加载；目标数量选择零 AI 请求；显式重新规划一次文本请求；实际草稿数量应用；连续性/机位默认折叠；图片、稳定 ID 和历史保留；窄屏无页面横向溢出。
2. 素材：空画格参考不覆盖共同资产；static 别名去重；实际上传字节摘要、清单顺序和提示词编号逐项对应；一宫格一次模型调用，自动采用/本地切格无额外调用；缺失绑定资产在排队前拒绝。
3. 宫格连续性：上一分镜真实末格进入实际输入；上游末格变更标记候选过期；场景切换不上传上一场景图片；不自动追加调用。
4. 微调：整图指定格、单格原图精修、多格微调、两页共用点格入口、采用与丢弃、分辨率持久化、规划保存和版本记录。六次显式图片生成对应六次请求，未选格的完整对象保持一致。
5. 视频连续性：Wan 的实际请求只含 first_frame/last_frame；前镜尾帧与后镜首帧实际上传摘要一致；快照落库与输出保留；上游变更标记下游过期。Seedance 自动回退保留理由，明确首尾帧选择在模型请求前拒绝。

模拟验证证明输入、调用次数和状态流转正确，不证明真实模型的人物、动作、场景或视频运动质量。共享输入图片可强化边界约束，不保证两个视频的实际输出像素或运动速度完全一致；本轮未加入实际视频抽帧串联。远程图片相同 URL 下内容被替换，readonly GET 不会联网识别；任务仍使用冻结字节。端点目前支持 PNG/JPEG/WebP。
