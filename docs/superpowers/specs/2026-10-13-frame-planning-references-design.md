# 单分镜宫格规划与参考素材

用户撤回跨分镜联合宫格方案，要求继续一个分镜生成多个画面，并优化 AI 规划、保证宫格生图使用参考素材。跨分镜分组工作区已停止并归档，不合并到 dev。

## 用户流程

一个已有分镜 → AI 规划 1～9 个连续静态瞬间 → 审核文字规划 → 一次图片模型调用生成一张宫格 → 审核采用 → 保留整图指定格微调和切图单格精修。两种微调继续使用已采用原图；规划和生图分别由用户发起，不自动串联收费调用。

规划窗口改为“宫格画面规划”，明确一个分镜对应一张宫格。画面按时间排序，优先展示标题、静态画面描述；连续性和景别、机位、构图放在可展开区域。共同约束默认显示摘要，可展开编辑。数量选择只修改本地期望值；点击“重新规划”才请求文字模型。应用时只保存已显示的规划，数量尚未重新规划时提示实际采用数量。

## AI 上下文与规则

服务端将当前分镜的 description、imagePrompt、videoPrompt、时长、镜头参数、现有有序画面和已绑定资产的身份/外貌/服装、场景空间/光线、道具真实描述、参考清单、作品风格直接写入规划请求，避免模型遗漏工具调用后凭空规划。只读工具仍可用于补充；已有上下文时不必再调用工具。

按照原分镜动作顺序先识别起始状态、关键变化、结束状态，再选指定数量的关键瞬间。描述决定事件和切镜顺序，videoPrompt 补充时间/动作节奏，imagePrompt 锚定视觉外观，参考资产定义身份/空间/道具，不把主画面提示词机械复制到所有格。不新增情节，不无依据换手、换位、换服装。剧情明确发生的场景/机位变化应声明为允许变化，不能盲目强制所有格背景相同。

每格只写一个可见静态状态；continuity 明确上格状态、实际变化、当前状态。第一格明确起始状态；最后一格呈现本段结束状态。单格选代表性瞬间。数量不足时优先保留动作关键转折，不能将完整动作过程塞入一格。稳定 ID、合法已有时间点与旧图片保留。规则回退继续标记“规则草稿”，不伪装成 AI 结果。

规划前后校验任务输入指纹；处理期间分镜或资产资料变化则明确失败，避免发布过期结果。同一输入、数量和模型的活动任务复用；活动任务尚未完成时拒绝改数量重置，避免重复收费和旧结果覆盖新请求。

## 实际参考图片

共享参考清单模块用于只读预览和提交前验证：已绑定 sceneId、characterIds、propIds 对应图片是共同参考；panel.referenceImages 是共同自定义参考；frame.referenceImages 是额外格级参考。格级空数组不能屏蔽共同参考。按图片规范化路径去重，保留同一图片对应的多个素材标签。排列顺序、参考编号与发送给模型的图片顺序完全一致。

GET /animatic-versions/:id/grid-references?panel_id=... 返回 `{items:[{url:string|null,label:string,kind:'scene'|'character'|'prop'|'custom',required:boolean}],ready:boolean,error:string}`。可列出尚未生成的已绑定素材；读取不调用模型、不冻结/写图片、不读取远程图片。POST 生图重新解析并验证清单，缺少绑定资产图、不可读图片、超出引用数量/字节限制时不得排队或调用模型。未绑定且没有任何参考的分镜提示先绑定或上传参考素材；整组生成至少需要一张参考，微调仍以原图为基础。

候选视图新增 referenceAssets，记录提交时实际参考清单（url 为冻结文件、digest、label、kind、required、可选 sourceUrl），不泄露凭据或完整提示词。旧快照该字段缺省仍可读取。候选使用不可变冻结图片，生成 prompt 标明图片编号与角色/场景/道具名，并加入原分镜描述、静态序列与明确的允许变化。角标仍为界面叠加，不能由模型绘制或进入成片。

工具栏附近显示紧凑“参考素材 N 张”及缩略图，展开查看准确名称；缺失项显示原因和绑定提示。两页使用同一组件。保存后再校验参考清单，画面/配置切换应丢弃过期请求；审核时显示候选冻结参考信息。

## 验收

单分镜 N 格保持原语义；数量修改无请求，明确重规划只有一次文字任务；上下文包含 imagePrompt 和完整资产，提示词层在中文/英文/日文/韩文与 inline/skill 中一致。共享素材不会被格级空数组屏蔽；重复 static 路径只发送一次；参考顺序和编号一致；缺失图在收费前失败；候选参考与实际 multipart 字节对应。保留旧画面、历史、采用租约、取消与两种微调行为。自动测试、类型检查、生产构建及隔离数据库/模拟模型浏览器验证通过后合入本地 dev。
