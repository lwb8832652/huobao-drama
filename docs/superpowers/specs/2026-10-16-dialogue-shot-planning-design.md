# 对白与镜头统一规划设计

用户于2026-10-16批准整集诊断后的推荐方案。本次范围：对白完整性、真实时间预算、单分镜宫格与视频镜头映射、生成前诊断、修复预览与应用。保留现有媒体，不自动调用付费生成。

引入纯领域模块 shot-planning.ts：结构化对白、子镜头、时间窗口、诊断和可确定重排。对白按说话人和语义保留，允许声画并行；预算默认4字/秒并加标点、换人和首尾余量。输入超载不得静默删词。旧数据从描述与提示词解析，供诊断和修复使用；没有计划时不自动改写。计划保存到工作版Panel，避免新增独立数据库表。派生提示词与画面规划上下文采用同一个计划。

修复接口返回整集或所选分镜的预览，包含现有/建议时长、建议连续生产段、对白完整性与需重规划画面。应用时按revision和输入摘要重算，不接受客户端伪造计划；在事务内保存新工作版、同步分镜与绑定、保留旧版本和历史媒体。拆段只在时长能力不足时发生；保守使用15秒单段预算，避免把nuwax服务声明30秒误当成具体工作流已验证能力。

生成前阻止对白遗漏、确定超载、时间缺口和空画面；保存编辑仍允许，不锁死修复操作。新拆分提示词取消固定3秒与固定镜头数量。画面兜底按子镜头/可视动作解析，规则草稿需显式人工确认。画面数量按内容推荐，支持1—9，不默认固定4。UI在视频提示词附近提供紧凑质量检查和整集优化弹窗，可预览、选段、应用；应用不自动生图/视频。

验证：用真实分镜2/6/3/4与标点闭引号回归，包含脚本覆盖、分段不丢词、时长范围、旧版兼容、并发版本冲突、媒体保留、生成阻断、页面预览取消/应用。成片ASR接入作为后续能力，本次明确展示输入规划检查不等于成片听审通过。

补充边界：单段最多9个可视子镜头以满足宫格覆盖；超出时保留全部内容并拆段。脚本对白恢复携带原文跨度，防止相同对白替错角色。说话人比较规范化“说/说道/问/回答”等发声动词，多角色含糊表述不猜测归属。图片和整组宫格生成同样要求完成重规划审阅。
