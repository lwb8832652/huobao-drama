# 分镜宫格与视频参考输入设计

## 目标

单个分镜支持 1～9 张按时间推进的画面，并通过宫格统一服务于分镜列表预览、画面面板概览和视频参考输入。原始画面是唯一真实数据，宫格图是根据原始画面生成的派生资源。

## 设计决策

### 画面数量

- 单个分镜支持 1～9 张画面。
- AI 拆分、按描述规划、手动添加和保存校验使用同一数量范围。
- AI 可以按照分镜时长给出推荐数量，用户可以明确选择 1～9 中的任意数量。
- 已有超过 9 张的历史数据保留，但禁止继续新增，需整理后才能生成视频。

### 宫格布局

| 有效画面数 | 布局 |
| ---: | :--- |
| 1 | 1×1 |
| 2 | 2×1 |
| 3～4 | 2×2 |
| 5～6 | 3×2 |
| 7～9 | 3×3 |

画面先按时间点升序排列，时间点相同则保持当前顺序，然后按行从左到右、从上到下放置。宫格使用项目视频比例的固定画布，单格完整适配，禁止拉伸和裁切。布局剩余的空格使用中性背景，不显示序号且不可点击。

### 两种宫格资源

系统保留两种派生图：

- **标注宫格**：用于分镜列表、概览态和用户查看，包含 1～N 序号角标。
- **干净宫格**：用于视频模型输入，默认不含角标、边框、分隔线和文字。

宫格记录来源画面 ID、时间点、布局、项目画布比例、原始画面内容指纹、标注图地址、干净图地址、合成状态、失败原因和生成时间。

新增、删除、排序、修改时间点、上传、重新生成或切换历史图片后，宫格标记为过期并重新合成。

### 提示词引用

视频提示词需要声明宫格的空间顺序和时间关系，例如：

> 参考图为本分镜的宫格图，共 5 个有效画面，按从左到右、从上到下排列。第 1 格对应 0.0 秒，第 2 格对应 1.8 秒，第 3 格对应 3.6 秒，第 4 格对应 5.4 秒，第 5 格对应 7.2 秒。请生成连续的全屏视频。

提示词必须说明序号、边框、分隔线和空白区域仅用于参考定位，不得出现在成片中，也不得生成宫格、分屏、拼贴或带文字的视频画面。该声明用于降低残留概率，最终效果仍需通过实际视频验收。

使用标注宫格时，提示词可以引用“角标 N”；使用干净宫格时，提示词改用“第 N 格”和时间点描述，不依赖图片中的可见角标。

### 视频参考输入策略

`storyboard_frames` 提供三种策略：

| 策略 | 行为 |
| --- | --- |
| `auto` | 根据模型参考图上限自动选择 |
| `individual` | 逐张传入原始画面 |
| `contact_sheet` | 每个分镜传入一张干净宫格 |

`auto` 按以下规则选择：

1. 单个分镜的原始画面数量不超过模型上限时，使用 `individual`。
2. 超过模型上限时，使用该分镜的一张干净宫格。
3. 按组生成时，每个分镜最多提供一张宫格，保持分镜边界，不合并成跨镜头大宫格。
4. 组内分镜数量仍超过模型上限时，阻止提交并提示改为按分镜生成或减少输入范围。
5. 禁止静默截断后面的画面。

使用 `individual` 时，只要求原始画面全部完成；使用 `contact_sheet` 时，要求干净宫格已完成；使用 `auto` 时，按最终选择的输入策略校验。视频任务提交时固定画面顺序、宫格版本、输入策略和提示词快照。

### 列表和面板交互

分镜列表没有视频时显示标注宫格；视频完成后优先显示视频预览，宫格作为海报、详情预览和视频失败后的回退图。

画面面板支持概览态和编辑态：

- 概览态显示完整宫格、完成数量、宫格状态、输入策略和操作入口。
- 点击有效格打开对应画面的生成设置。
- 点击待生成格打开对应画面的生成设置。
- 点击布局空白格无操作。
- 编辑态保留现有逐张卡片，以及生成、上传、历史图片、排序、删除和生成设置功能。

### 状态与失败处理

画面状态包括未生成、生成中、已完成和生成失败；宫格状态包括未生成、合成中、已完成、已过期和合成失败。

宫格合成失败时提供重试，不能静默使用旧宫格。使用宫格作为视频输入时，宫格未完成或已过期则阻止提交，并显示具体原因。使用逐张原图时，宫格更新失败不阻塞视频生成，但界面需要显示宫格过期状态。

## 验收标准

1. 1～9 张画面对应正确的宫格布局。
2. 3、5、7 张画面时，空白格位置正确且不可点击。
3. 时间点调整后，宫格顺序正确；相同时间点保持稳定顺序。
4. 替换历史图片后，宫格进入过期状态并可重新合成。
5. 概览态点击每个有效格都能定位到正确画面设置。
6. 编辑态原有逐张操作全部保留。
7. `individual` 实际发送 N 张原图，`contact_sheet` 实际发送 1 张干净宫格。
8. `auto` 超过模型限制时自动切换宫格，仍超限时不创建部分任务。
9. 组视频按“每个分镜一张宫格”计算输入数量。
10. 宫格合成失败可重试，过期宫格不会被静默复用。
11. 生成结果验收时不应出现宫格、边框、角标、分隔线和序号；发现残留时保留输入快照，便于调整模型或提示词策略。

## 分阶段范围

第一阶段实现画面数量、宫格布局、列表预览和概览/编辑双态；第二阶段加入视频输入策略、干净宫格和模型上限校验；第三阶段根据实际视频结果优化提示词、角标残留处理、任务快照和失败重试。
